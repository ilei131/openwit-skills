# 04 验收标准（每章通用）

> 每章写完后逐条核对，全部通过方可标记"已完成"并进入下一章。

## 硬性指标

1. **字数**：正文（不含标题）在 `book.json` 指定的区间内；净字数按汉字与数字计，不含标点与空白。
2. **五要素齐备**：开场钩子 / 明确目标 / 有效冲突 / 人物（内容）变化 / 结尾推进。
3. **结尾钩子**与目录/总纲中该章"章末钩子"一致（可措辞不同，指向须一致）。
4. **术语一致**：命中《03_术语表.md》，不出现别名乱用。
5. **声音符合**：对照《02_写作规范.md》，无串味。
6. **无重复**：与既往章节无重复句、重复比喻、重复桥段（脚本 + 人工抽查）。
7. **承诺/伏笔**：该章涉及的承诺/伏笔已按计划埋设或回收，并已登记进《06_连续性档案.md》。
8. **连续性档案**：
   - [ ] 已新增本章状态卡（时间/地点/在场人物/人物状态/知情矩阵/物品状态/章末未决）
   - [ ] 已更新实体台账中受影响的人物、物件、地点
   - [ ] 已更新承诺/伏笔台账（新增取新编号，回收改状态）
   - [ ] 已更新滚动摘要（最近 3 章详细，更早章节一句话）
9. **禁忌**：未违反《02_写作规范.md》禁忌清单任何一条。
10. **编号**：章节序号、卷序与《01_目录.md》一致。
11. **AI 味**：`scripts/ai_lint.py` 的 blocking 项为 0，或每一处都在 `book.json` 的 `ai_ignore` 中登记为有意保留。

## 改稿附加验收

- [ ] 改前原稿已备份到 `work/改前原稿/`
- [ ] 改动范围符合用户授权：只改表达 / 允许结构调整 / 允许改剧情
- [ ] 只改表达时，事实、人物选择、因果、伏笔、揭露顺序均未改变
- [ ] 剧情级改动已同步更新状态卡、实体台账、承诺/伏笔台账与滚动摘要
- [ ] 改后已重跑 `check.py` 与 `ai_lint.py`

- 连续性信息追加进《06_连续性档案.md》。
